# ADR-0005: 図の表示対象と配置情報の保存先

- 状態: 採用
- 日付: 2026-10-07

## 背景

モックは配置情報をテキスト内の `/* @layout {...} */` コメントに、図のタブを localStorage に保存している。
コメント方式は一元管理できる反面、座標の変更がモデルの差分に混ざり、同じ要素を複数の図で別の位置に置けない。

## 決定

| 情報 | 保存先 |
| --- | --- |
| どの図にどの要素を出すか（タブの中身） | テキスト内の SysML v2 標準 `view` |
| 座標・線の経路 | テキストの隣の別ファイル（例: `model.sysml` → `model.layout.json`） |

- 配置ファイルは修飾名をキーにし、キー順を固定、1 要素 1 行で書き出す（差分・マージを読みやすくするため）。
- 名前変更はコアがテキストと配置ファイルを同時に更新する。
- 対応する要素が無い配置エントリは検査で警告する。
- 移行期は `@layout` コメントを読み込み専用でサポートし、保存時に別ファイルへ移す。

## 結果

- モデルの差分レビューから座標の変更が消える。
- 他の SysML v2 ツールでもテキストと `view` は読める。
