# Modelith 0.1.0-rc.2

0.1.0 の正式版の 2 つめの候補（rc）です。同じフォルダを新しい版（プレビュー版）と行き来して開いても、図の配置ファイルを壊さないようにしました。1 週間ほど使っていただき、重大な不具合が見つからなければ、この内容で 0.1.0 を出します。

## 新しい機能

- プラグインが動く版：プラグインの説明のファイル（`modelith-plugin.json`）に、動く Modelith の版を `"engines": { "modelith": ">=0.1.0, <0.3.0" }` のように書けるようになりました。書いた範囲に入らない版の Modelith では、プラグインを動かさず、理由を示します

## 不具合の修正

- 新しい版で調整した線が消える：プレビュー版で線の形を調整した図を、この版で開いて要素を動かして保存すると、線の調整が消えていました。この版の知らない項目は、保存するときにそのまま残すようになりました
- 読めない配置ファイルの上書き：読めない配置ファイルや、新しい版の形式の配置ファイルを開いて要素を動かすと、そのファイルを書き換えていました。開いたときにそのことを知らせ、配置ファイルは書き換えないようになりました

## その他

- 正式版の候補を試せる場所：正式版の候補は、https://modelith.github.io/modelith/rc/ でも試せるようになりました。0.1.0 を出すまでは、いつもの https://modelith.github.io/modelith/ と同じ版です

## ご注意

- 開発中の版のため、操作方法や保存形式は予告なく変わることがあります。
- 本ソフトウェアは無保証です。
- フォルダを開いてファイルを直接保存できるのは、Chrome と Edge です。
- 保存先のないファイル（新規作成したファイルやサンプル）は、ブラウザ内に下書きとして一時的に残るだけです。必要なものは「名前を付けて保存」で保存してください。
