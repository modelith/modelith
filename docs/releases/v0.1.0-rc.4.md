# Modelith 0.1.0-rc.4

0.1.0 の正式版の 4 つめの候補（rc）です。rc.3 を試していただく中で見つかった、関係や下書きが失われる不具合と、図の操作の不具合を直しました。1 週間ほど使っていただき、重大な不具合が見つからなければ、この内容で 0.1.0 を出します。

## 改善

- 名前の変更の知らせ：要素を置いた直後に名前を付けると、「このファイルの中で使っている箇所も変えました」と、まだ無い参照の話が出ていました。宣言のほかにも書き換えた箇所があるときだけ、そう添えるようになりました
- 自動保存できないときの案内：開いているファイルがほかのアプリで削除されていて自動保存できないとき、「名前を付けて保存」で保存し直せることを示すようになりました（保存の操作では rc.3 から示しています）
- 設定ファイルのエラーの位置：modelith.json のエラーに、行に加えて何文字目かも示すようになりました。また、// や /* */ のコメントを書くと「項目の名前は「"」で囲んでください」と出ていましたが、コメントは書けないことを示すようになりました

## 不具合の修正

- 相手が複数ある関係からの削除：`dependency from A to B, C;` のように相手を並べた関係で、図から C を削除すると、文がまるごと消え、A から B への関係も失われていました。消した要素だけを並びから外すようになりました
- 名前の変更で変わる範囲：定義の名前を変えると、ほかのパッケージにある同じ名前の定義と、それを使う箇所まで変わっていました。名前を書いた場所から、どの定義を指すかを確かめ、選んだ定義を指す箇所だけを変えるようになりました
- 複数のタブでの下書き：同じブラウザで Modelith を 2 つのタブで開いて使うと、片方のタブで書いた新しいファイルの下書きが、もう片方のタブの保存で消えていました。ほかのタブの下書きを残すようになりました
- 下書きに残せないときの警告：前回の下書きが新しい版（プレビュー版）の形で残っていると、新しいファイルを書いたままページを閉じても警告が出ず、書いた内容が失われていました。下書きに残せないことを知らせ、閉じる前に警告するようになりました
- 内部ブロック図の引用符で囲んだ名前の部品：'the lamp' のように引用符で囲んだ名前の部品をつなぐ接続や流れが、内部ブロック図と draw.io のエクスポートに描かれていませんでした。描くようになりました（rc.3 で直したのは、ポートの名前と、遷移・メッセージの端でした）
- テキストの書き方で使う言葉の名前：要素の名前を def・part・end などに変えると、テキストが壊れ、要素が図から黙って消えていました。理由を示して断るようになりました。テキストにこれらの言葉を名前として書いたときも、問題一覧で知らせ、'def' のように引用符で囲む書き方を示すようになりました
- パッケージと同じ名前の図：パッケージと同じ名前で図を作れてしまい、ほかの図の要素が「見つかりません」になって空になっていました。理由を示して断るようになりました。また、名前を断ったときにダイアログが閉じて入れた名前が消えていましたが、入れた名前のまま開き直すようになりました
- 作成した図を表示しているときの「新しい図を作成」：図のメニューから選んでも何も起きませんでした。作れない理由を示すようになりました
- 要素の削除と作成した図：要素を削除しても、テキストに `expose 名前;` と修飾なしで書いた図の指定が残り、「見つかりません」と出ていました。一緒に削除するようになりました
- 入力欄の元に戻す：説明・名前の変更・絞り込みなどの入力欄で、戻すものが無いときに Ctrl+Z を押すと、テキストの入力やモデルの編集が戻っていました。その欄の中だけを戻すようになりました
- キーボードでのエクスプローラーの操作：ファイル・フォルダ・開いているファイルの行に Tab で移れず、キーボードだけではファイルを開いたり切り替えたりできませんでした。Tab で移り、Enter か Space で開けるようになりました。選んでいないファイルの「×」にも届くようになりました
- プラグインが動く版の誤った書き方：modelith-plugin.json の `engines.modelith` に `>=0.2.0-beta.1 || 0.1.x` のような使えない書き方をすると、「-」から後ろを読み捨てて別の意味に読んでいました。書き方の誤りとして知らせるようになりました

## ご注意

- 開発中の版のため、操作方法や保存形式は予告なく変わることがあります。
- 本ソフトウェアは無保証です。
- フォルダを開いてファイルを直接保存できるのは、Chrome と Edge です。
- 保存先のないファイル（新規作成したファイルやサンプル）は、ブラウザ内に下書きとして一時的に残るだけです。必要なものは「名前を付けて保存」で保存してください。
