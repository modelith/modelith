# Modelith 0.2.0-beta.1

0.2.0 に向けた最初の beta 版です。0.2.0 の機能はここで固定し、0.2.0 までは不具合の修正だけを行います。

## その他

- 機能の固定：alpha 版で加えてきた、図を作る・画面での編集・図の不足を埋める・複数のファイルにまたがるモデル・線の調整・エクスポートの強化・知らせの重さ・プロジェクトの一覧などの機能を、この版で固定しました。0.2.0 までは、不具合の修正だけを行います。気になる振る舞いがあれば、[GitHub Issues](https://github.com/modelith/modelith/issues/new/choose) でお知らせください
- 開発段階の表示：画面左上の札と「ヘルプ」に、beta 版であることを表示します

## ご注意

- 開発中の版のため、操作方法や保存形式は予告なく変わることがあります。
- 本ソフトウェアは無保証です。
- フォルダを開いてファイルを直接保存できるのは、Chrome と Edge です。
- 保存先のないファイル（新規作成したファイルやサンプル）は、ブラウザ内に下書きとして一時的に残るだけです。必要なものは「名前を付けて保存」で保存してください。
