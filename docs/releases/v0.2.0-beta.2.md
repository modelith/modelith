# Modelith 0.2.0-beta.2

0.2.0 に向けた 2 つめの beta 版です。0.2.0-beta.1 から、機能と画面の変更はありません。

## その他

- 開発の環境の更新：Modelith を組み立てて確かめる環境を新しくしました。アプリの動きと保存形式は beta.1 と同じです。気になる振る舞いや不具合があれば、[GitHub Issues](https://github.com/modelith/modelith/issues/new/choose) でお知らせください

## ご注意

- 開発中の版のため、操作方法や保存形式は予告なく変わることがあります。
- 本ソフトウェアは無保証です。
- フォルダを開いてファイルを直接保存できるのは、Chrome と Edge です。
- 保存先のないファイル（新規作成したファイルやサンプル）は、ブラウザ内に下書きとして一時的に残るだけです。必要なものは「名前を付けて保存」で保存してください。
