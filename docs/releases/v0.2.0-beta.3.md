# Modelith 0.2.0-beta.3

0.2.0 に向けた 3 つめの beta 版です。同じフォルダを版の違う Modelith（安定版・リリース候補版・プレビュー版）で行き来して開いても、図の配置ファイルや下書きを壊さないようにしました。

## 新しい機能

- プラグインが動く版：プラグインの説明のファイル（`modelith-plugin.json`）に、動く Modelith の版を `"engines": { "modelith": ">=0.2.0, <0.3.0" }` のように書けるようになりました。書いた範囲に入らない版の Modelith では、プラグインを動かさず、理由を示します

## 不具合の修正

- 新しい版で足した項目が消える：この版の知らない項目を含む配置ファイルを開いて要素を動かして保存すると、その項目が消えていました。この版の知らない項目は、保存するときにそのまま残すようになりました
- 読めない配置ファイルの上書き：読めない配置ファイルや、新しい版の形式の配置ファイルを開いて要素を動かすと、そのファイルを書き換えていました。開いたときにそのことを知らせ、配置ファイルは書き換えないようになりました
- 新しい版の下書きが消える：新しい版の Modelith が残した下書きのうち、この版の知らない形のものを、下書きを保存するときに消していました。そのまま残すようになりました

## その他

- 正式版の候補を試せる場所：正式版の候補（rc）は、https://modelith.github.io/modelith/rc/ で試せるようになりました。プレビュー版とは別に保存されるので、前回の続き・下書き・設定・プラグインの許可は引き継がれません

## 0.2.0-beta.2 をお使いの方へ

- 線の形を調整した図の配置ファイル：線の折れ点や、線をつなぐ位置を調整した図を保存すると、配置ファイルに `"requires": ["edge-shapes"]` を書くようになりました。線の調整を知らない版（0.1.0 の候補 0.1.0-rc.2 など）でこのファイルを開くと、図は表示しますが、配置ファイルは書き換えません。線の調整を消してしまわないためです。線の調整をやめると、この項目も消えます

## ご注意

- 開発中の版のため、操作方法や保存形式は予告なく変わることがあります。
- 本ソフトウェアは無保証です。
- フォルダを開いてファイルを直接保存できるのは、Chrome と Edge です。
- 保存先のないファイル（新規作成したファイルやサンプル）は、ブラウザ内に下書きとして一時的に残るだけです。必要なものは「名前を付けて保存」で保存してください。
