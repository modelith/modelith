# Modelith 0.2.0-beta.5

0.2.0 に向けた 5 つめの beta 版です。0.2.0-beta.4 の試用で見つかった不具合を直しました。あわせて、0.1.0-rc.4 の修正も入っています。

## 改善

- 見つからない相手の知らせ：`part def P :> Nope;`（引き継ぐ定義）・`alias T for Nope;`（別名）・`import Nowhere::*;`（インポート）の相手が見つからないとき、問題一覧に何も出ていませんでした。「見つかりません」と知らせるようになりました。標準ライブラリの名前と、フォルダのほかのファイルの名前は知らせません
- 名前の変更の知らせ：要素を置いた直後に名前を付けると、「このファイルの中で使っている箇所も変えました」と、まだ無い参照の話が出ていました。宣言のほかにも書き換えた箇所があるときだけ、そう添えるようになりました
- 自動保存できないときの案内：開いているファイルがほかのアプリで削除されていて自動保存できないとき、「名前を付けて保存」で保存し直せることを示すようになりました
- 設定ファイルのエラーの位置：modelith.json のエラーに、行に加えて何文字目かも示すようになりました。また、// や /* */ のコメントを書くと「項目の名前は「"」で囲んでください」と出ていましたが、コメントは書けないことを示すようになりました

## 不具合の修正

- 相手が複数ある関係からの削除：`dependency from A to B, C;` のように相手を並べた関係で、図から C を削除すると、文がまるごと消え、A から B への関係も失われていました。消した要素だけを並びから外すようになりました
- 名前の変更で変わる範囲：定義の名前を変えると、ほかのパッケージにある同じ名前の定義と、それを使う箇所まで変わっていました。選んだ定義を指す箇所だけを変えるようになりました
- 属性の名前の変更：インスペクタで属性の名前を変えると、同じ定義の中の参照しか変わらず、`:>> 名前`（引き継いだ属性の値を変える書き方）・`部品.名前`・`定義::名前` が古い名前のまま残っていました。その属性を指す参照をまとめて変えるようになりました
- 複数のタブでの下書き：同じブラウザで Modelith を 2 つのタブで開いて使うと、片方のタブで書いた新しいファイルの下書きが、もう片方のタブの保存で消えていました。ほかのタブの下書きを残すようになりました
- 下書きに残せないときの警告：前回の下書きがこれより新しい版の形で残っていると、新しいファイルを書いたままページを閉じても警告が出ず、書いた内容が失われていました。下書きに残せないことを知らせ、閉じる前に警告するようになりました
- 内部ブロック図の引用符で囲んだ名前の部品：'the lamp' のように引用符で囲んだ名前の部品をつなぐ接続や流れが、内部ブロック図と draw.io のエクスポートに描かれていませんでした。描くようになりました
- テキストの書き方で使う言葉の名前：テキストに `part def def;` のように、def・part・end などを名前として書くと、問題一覧に何も出ずに要素が消えていました。問題一覧で知らせ、'def' のように引用符で囲む書き方を示すようになりました
- 新しい図の名前：パッケージと同じ名前で図を作れてしまい、ほかの図の要素が「見つかりません」になって空になっていました。理由を示して断るようになりました。名前を断ったときは、入れた名前と種類のままダイアログを開き直すようになりました。また、図の名前に「'」を使えていましたが、要素の名前と同じく断るようになりました
- 同じ「検証する」関係：要求と検証の間に「この検証で確かめる」を 2 回追加すると、同じ文が 2 つ書かれていました。「満たす」・導出と同じく、理由を示して断るようになりました
- 要素の削除と作成した図：要素を削除しても、テキストに `expose 名前;` と修飾なしで書いた図の指定が残り、「見つかりません」と出ていました。一緒に削除するようになりました
- 入力欄の元に戻す：説明・名前の変更・絞り込みなどの入力欄で、戻すものが無いときに Ctrl+Z を押すと、テキストの入力やモデルの編集が戻っていました。その欄の中だけを戻すようになりました
- キーボードでのエクスプローラーの操作：ファイル・フォルダ・開いているファイルの行に Tab で移れませんでした。Tab で移り、Enter か Space で開けるようになりました。選んでいないファイルの「×」にも届くようになりました
- 配置ファイルの形：配置ファイルの図の一覧（views）が配列で書かれていると、知らせずに書き換えていました。形の違う配置ファイルとして知らせ、書き換えないようになりました
- 幅の狭い画面の全体図：スマホなどの幅の狭い画面でインスペクタを開くと、全体図が拡大縮小のボタン（「全体図」）に重なっていました。重ならないように寄せるようになりました
- プラグインが動く版の誤った書き方：modelith-plugin.json の `engines.modelith` に `>=0.2.0-beta.1 || 0.1.x` のような使えない書き方をすると、別の意味に読んでいました。書き方の誤りとして知らせるようになりました

## ご注意

- 開発中の版のため、操作方法や保存形式は予告なく変わることがあります。
- 本ソフトウェアは無保証です。
- フォルダを開いてファイルを直接保存できるのは、Chrome と Edge です。
- 保存先のないファイル（新規作成したファイルやサンプル）は、ブラウザ内に下書きとして一時的に残るだけです。必要なものは「名前を付けて保存」で保存してください。
