# Modelith 0.2.0-rc.1

0.2.0 の正式版の候補（rc）です。0.2.0-beta.5 から機能は変えず、複数のファイルがあるフォルダで図から編集できなかった不具合を直しました。1 週間ほど使っていただき、重大な不具合が見つからなければ、この内容で 0.2.0 を出します。

## 不具合の修正

- 複数のファイルがあるフォルダでの名前の変更：フォルダにファイルが 2 つ以上あると、表示中のファイルの定義の名前を図から変えようとしても、「ほかのファイルの要素です」と断っていました。表示中のファイルの要素は、変えられるようになりました
- 複数のファイルがあるフォルダでの要素の追加：ほかのファイルに同じ種類の定義（部品定義・要求など）があると、パレットからその種類を図に置けませんでした。表示中のファイルに置くようになりました
- 複数のファイルがあるフォルダでの削除と関係の追加：ほかのファイルに依存の関係や「満たす」・導出の関係があると、表示中のファイルの要素を削除できなかったり、関係を足せなかったりしていました。表示中のファイルの中で行うようになりました

## その他

- 正式版の候補：画面左上の札と「ヘルプ」に、正式版の候補（rc）であることを表示します。気になる振る舞いや不具合があれば、[GitHub Issues](https://github.com/modelith/modelith/issues/new/choose) でお知らせください
- 試せる場所：リリース候補版（<https://modelith.github.io/modelith/rc/>）とプレビュー版（<https://modelith.github.io/modelith/preview/>）で試せます。リリース候補版の前回の続き・下書き・設定は、安定版（0.1.0）ともプレビュー版とも別に保存されます

## ご注意

- 開発中の版のため、操作方法や保存形式は予告なく変わることがあります。
- 本ソフトウェアは無保証です。
- フォルダを開いてファイルを直接保存できるのは、Chrome と Edge です。
- 保存先のないファイル（新規作成したファイルやサンプル）は、ブラウザ内に下書きとして一時的に残るだけです。必要なものは「名前を付けて保存」で保存してください。
