# Modelith 0.2.0-rc.2

0.2.0 の正式版の 2 つめの候補（rc）です。0.2.0-rc.1 を出す前の確かめで見つかった、図からの削除や名前の変更の不具合を直しました。1 週間ほど使っていただき、重大な不具合が見つからなければ、この内容で 0.2.0 を出します。

## 不具合の修正

- 状態やアクションの削除：状態やアクションを図から削除すると、それを指す遷移・順序の文がテキストに残り、「見つかりません」と出ていました。その要素を端にする遷移・順序・流れの文も一緒に消すようになりました
- 名前に「::」を含む要素：要素の名前を「::」を含む名前に変えると、その要素への線が図から消えていました。「::」を含む名前は、理由を示して付けられないようにしました。手で `part def 'a::b';` と書いた名前は、まだ正しく扱えません
- ほかのファイルの図に出している要素の削除：ほかのファイルの図に出している要素を削除しようとすると、「ほかのファイルの要素です」と誤った理由を示していました。その図のあるファイルを示し、先に図から外すよう案内するようになりました
- 空の図に続けて入れた要素：空の図にモデルのツリーの「追加」で要素を続けて入れると、同じ位置に重なっていました。既にある要素を避けて、下に並べて置くようになりました
- 見つからない「引き継ぐ定義」と「別名」の知らせ：標準ライブラリを `import ISQ::*;` のように取り込んでいると、見つからない「引き継ぐ定義」と「別名の指す先」を知らせていませんでした。型と同じ基準で知らせるようになりました
- 引用符で囲んだ名前の表示：`part def 'a\'b';` の名前が、図・ツリー・エクスポートで `a\'b` とそのまま出ていました。`a'b` と表示するようになりました。名前が空の要素（`''`）は、何も知らせずに図から消えていましたが、問題一覧で知らせるようになりました
- 状態遷移図を開いたときの表示：状態が横に並ぶ状態遷移図を開くと、右端が図の枠からはみ出すことがありました。少し縮めれば収まる図は、開いた時点で全体を表示するようになりました

## 0.2.0-rc.1 をお使いの方へ

- アクティビティ図の途中のアクションの削除：順に並んだアクションの途中の 1 つを図から削除すると、これまでは前後のアクションが自動でつながっていました。この版から、削除したアクションにつながる順序だけを消し、前後は自動でつなぎません。続けたいときは、前のアクションから次のアクションへ「順序の線を追加」してください

## ご注意

- 開発中の版のため、操作方法や保存形式は予告なく変わることがあります。
- 本ソフトウェアは無保証です。
- フォルダを開いてファイルを直接保存できるのは、Chrome と Edge です。
- 保存先のないファイル（新規作成したファイルやサンプル）は、ブラウザ内に下書きとして一時的に残るだけです。必要なものは「名前を付けて保存」で保存してください。
