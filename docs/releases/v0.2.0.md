# Modelith 0.2.0

Modelith の 2 つめの正式版です。0.2.0-rc.2 から、機能と画面の変更はありません。0.1.0 からは、図の種類を選んで新しい図を作る・名前や属性を画面で編集する・フォルダの中の複数のファイルを 1 つのモデルとして読む・ファイルとフォルダを一覧から管理する、などが加わっています。

## その他

- 正式版：画面左上の札と「ヘルプ」から、正式版の候補（rc）の表示が無くなります。<https://modelith.github.io/modelith/> でお使いいただけます
- 0.1.0 からの変更の詳細：0.2.0 の各プレリリース（0.2.0-alpha.2〜0.2.0-rc.2）のリリースノートをご覧ください
- 次の版：0.3.0 は、プレビュー版（<https://modelith.github.io/modelith/preview/>）で試せます。前回の続き・下書き・設定は、正式版とは別に保存されます

## ご注意

- 開発中の版のため、操作方法や保存形式は予告なく変わることがあります。
- 本ソフトウェアは無保証です。
- フォルダを開いてファイルを直接保存できるのは、Chrome と Edge です。
- 保存先のないファイル（新規作成したファイルやサンプル）は、ブラウザ内に下書きとして一時的に残るだけです。必要なものは「名前を付けて保存」で保存してください。
