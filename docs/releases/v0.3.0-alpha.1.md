# Modelith 0.3.0-alpha.1

0.3.0 の最初のプレリリースです。Claude Code や Codex などの AI が、手元のフォルダのモデルを読み、確かめ、書き換え、図を書き出せるようにしました（MCP のサーバ）。ブラウザのアプリの画面と操作は、0.2.0-rc.2 から変わっていません。

## 新しい機能

- AI からモデルを読む：コマンド `modelith mcp <フォルダ>` を AI のクライアントに登録すると、AI がそのフォルダのモデルのファイル・要素の一覧・要素の中身（説明・型・関係）・図の一覧・問題一覧を取れます。問題一覧は、アプリの問題一覧と同じ内容です。使い方は [MCP のサーバ](https://github.com/modelith/modelith/blob/dev/docs/reference/mcp.md) にあります
- AI からモデルを書き換える：AI が、要素や関係の追加・名前の変更・削除・説明の書き換えを頼めます。書くのは 2 段階で、まず何も書かずに、変わる所と、書いたあとの問題一覧を返します。書き込むのは、その提案を指して頼んだときだけです。提案のあとにファイルが変わっていたら、上書きせずに断ります。書き換えるのは、指定したフォルダの中のモデルのファイルだけです
- 画面を開かずに図を書き出す：コマンド `modelith export <フォルダ> --format svg --diagram <図の名前>` と、AI からの頼みで、図を SVG・draw.io で書き出せます。配置と見た目はアプリと同じで、アプリで保存した配置があれば、その位置に描きます。図を作っていなくても、ブロック・状態定義・アクション定義・シナリオを指せば（`--subject <要素の名前>`）、その内部ブロック図・状態遷移図・アクティビティ図・シーケンス図を書き出せます
- コマンドの入れ方：Node.js 22 以上が入っていれば、このリリースに添付した `modelith-cli-0.3.0-alpha.1.tgz` から入れられます（`npm install -g https://github.com/modelith/modelith/releases/download/v0.3.0-alpha.1/modelith-cli-0.3.0-alpha.1.tgz`）。`npx modelith-cli` で使える形（npm への公開）は、まだです

## その他

- AI に渡るもの：`modelith mcp` は、手元のパソコンで動き、Modelith がモデルをどこかへ送ることはありません。モデルを読むのは、つないだ AI のクライアントです。AI のクライアントがモデルをどう扱うかは、そのクライアントの決まりに従います
- まだできないこと：AI からの名前の変更は、ほかのファイルにある参照を直しません（直っていない所は、提案の問題一覧に出ます）。PNG の書き出しは、まだありません

## ご注意

- 開発中の版のため、操作方法や保存形式は予告なく変わることがあります。
- 本ソフトウェアは無保証です。
- フォルダを開いてファイルを直接保存できるのは、Chrome と Edge です。
- 保存先のないファイル（新規作成したファイルやサンプル）は、ブラウザ内に下書きとして一時的に残るだけです。必要なものは「名前を付けて保存」で保存してください。
