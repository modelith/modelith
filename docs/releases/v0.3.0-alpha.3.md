# Modelith 0.3.0-alpha.3

0.3.0 の 3 つめのプレリリースです。書き誤った式と、同じ場所に 2 つある同じ名前を、問題一覧で知らせるようにしました。あわせて、図の線のラベルの重なりなど、見つかった不具合を直しました。

## 新しい機能

- 書き誤った式の知らせ：`attribute a = 1 + ;` のように、文法に合わない式を、問題一覧に構文エラーとして出すようにしました。これまでは、何も知らせずに読んでいました。知らせるのは、演算子の後に値が無い（`1 +`）・値の間に演算子が無い（`1 2`）・カンマの前後に値が無い（`f(a,)`）・`if` の式に `?` や `else` が無い・「.」や「->」の後に名前が無い、といった誤りです。値の式のほか、制約や計算の本体の式（`constraint def C { v > 10 }`）、絞り込みの式（`filter @Safety;`）、アクションと遷移の条件（`if`・`while`・ガード）や引数でも確かめます。式の計算と、式の中の名前が見つかるかの確かめはしません
- 同じ場所の同じ名前の知らせ：`part def A; part def A;` のように、同じパッケージや定義の直下に同じ名前の要素が 2 つあると、2 つめ以降を問題一覧に出すようにしました。これまでは何も出ませんでした。名前を書かずに引き継いだ特性を書き換える宣言（`:>> mass`）と、ほかのファイルの同じ名前は比べません
- 種類の語の書き誤りの知らせ：定義の中で `prt engine : Engine;` のように種類の語を書き誤ると、「「prt」という種類の要素はありません」と出すようにしました

## 改善

- 図の名前の変更を断られたとき：作成した図の名前を、既にある名前に変えようとして断られると、ダイアログが閉じていました。理由を示したうえで、入れた名前のままダイアログを開き直すようにしました
- 同じ線を 2 回足そうとしたとき：状態遷移図で同じ 2 つの状態の間に遷移を 2 回足すと、同じ文が 2 行書かれていました。きっかけや条件の無い同じ向きの遷移が既にあるときは、理由を示して足さないようにしました。アクティビティ図の順序の線も同じです

## 不具合の修正

- 重なる線のラベル：同じ 2 つの要素の間の線が同じ道を通ると、ラベルが同じ位置に重なって読めませんでした。後の線のラベルを 1 行ずつ下へずらして、どちらも読めるようになりました
- `if` で始まる式：計算や制約の本体に書いた `if a > 0 ? a else -a` のような式を、アクションの `if` として読んでいました。式として読むようになりました
- 名前の中の「::」：`'a::b'` のように「::」を含む名前を引用符で囲んで書くと、名前の区切りとして読み、「見つかりません」と出ることがありました。名前の一部として読むようになりました
- 型の定義のポートへの流れ：`flow a.out to b.in;` のように、部品の型の定義に書いたポートを端にした流れを、「見つかりません」と知らせることがありました。型の定義のポートも探すようになりました
- 読み込み直した後の未保存の印：保存していない新しいファイルは、ページを読み込み直すと中身は戻りますが、ファイル名の「●」（未保存の印）が消えていました。戻したファイルにも印を出すようになりました
- 画像のコピー：「エクスポート…」の「画像をコピー」を押しても、成功の知らせも失敗の知らせも出ないことがありました。押すたびに画像を作ってコピーするようになりました

## その他

- コマンドの npm での公開：`modelith` のコマンド（`modelith-cli`）を、npm から使えるようにしました。プレリリースの間は `npx modelith-cli@next` で使えます（安定版はまだ無いので、`@next` を付けないと動きません）。これまでどおり、このリリースに添付した `modelith-cli-0.3.0-alpha.3.tgz` からも入れられます

## 0.3.0-alpha.2 をお使いの方へ

- 書き誤った式や、同じ場所に 2 つある同じ名前を含むモデルでは、これまで出なかったエラーが問題一覧に出るようになります。図やツリーはこれまでどおり表示します。問題一覧の行を押して、その箇所を直してください

## ご注意

- 開発中の版のため、操作方法や保存形式は予告なく変わることがあります。
- 本ソフトウェアは無保証です。
- フォルダを開いてファイルを直接保存できるのは、Chrome と Edge です。
- 保存先のないファイル（新規作成したファイルやサンプル）は、ブラウザ内に下書きとして一時的に残るだけです。必要なものは「名前を付けて保存」で保存してください。
